# Third-party materials

The manifests identify public upstream repositories at specific commits. Their source code is fetched at runtime and remains subject to each upstream license. No license ownership is claimed over the upstream repositories.

The implementation retains its existing dependency-mapping source attribution. The source checkout did not provide a project LICENSE file. No new license or copyright ownership has been assigned during anonymous packaging. The authors must choose the project license and confirm redistribution rights before describing this as an open-source release.
